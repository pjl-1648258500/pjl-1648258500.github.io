# 千万级OD交通路径数据处理与出行特征构建

## 项目概述

该项目面向大规模OD交通数据处理需求，通过Python、Pandas、SQLite和外部地图服务，构建可恢复、可批处理的数据处理流程，将原始OD记录转化为标准化坐标、行政区划信息和结构化路线分段。

## 我的工作

- 负责数据处理流程的实现和运行。
- 设计地理编码、路线查询、结果缓存和数据库写入流程。
- 处理失败任务，设计重试与断点续传机制。
- 对公交路径中缺少时长和距离的末段步行记录进行识别与补齐。

## 技术路线

原始OD数据  
-> 地址与坐标标准化  
-> 行政区划匹配  
-> 公交、铁路和出租车路线查询  
-> 路线分段解析  
-> 异常任务记录  
-> 缓存复用与失败重试  
-> 步行末段补齐  
-> SQLite结构化存储

## 数据规模

- 原始OD记录约797万条。
- 标准化坐标与行政区划数据约795万条。
- 路线分段记录约4000万条。
- 待补齐步行记录约387万条。
- 去重后待查询坐标对约85万对。

## 关键难点

- 外部API存在QPS和调用额度限制。
- 长时间任务需要支持中断后的恢复。
- 重复坐标查询会造成额外调用和时间消耗。
- 部分路线结果存在缺失和结构不一致。
- 大规模数据写入需要控制内存和数据库事务规模。

## 解决方式

- 多API Key轮询。
- QPS控制和失败退避。
- 批量写入。
- 坐标和路线缓存。
- 断点续传。
- 独立失败任务表。
- 去重后再补齐步行数据。

## 项目成果

形成了从原始OD数据到结构化路线分段的完整处理流水线，提高了大规模外部API任务的稳定性、可恢复性和数据复用能力。

## 反思与后续方向

该项目不仅是数据清洗任务，也涉及交通路径数据的标准化表达。后续可进一步从路线分段、换乘结构、出行时长和空间联系等方面构建城市间出行特征。
