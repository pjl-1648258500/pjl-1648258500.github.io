# 乡村文旅数据采集与热点村庄识别平台

## 项目概述

该项目面向乡村文旅数字足迹研究需求，构建从地点发现、候选村庄筛选、任务生成到笔记数据整理和热点识别的完整数据流程。

## 我的工作

- 搭建城市定位、地点采集、候选筛选和数据整理流程。
- 将地点采集与笔记采集拆分为独立模块。
- 开发桌面GUI和全流程任务控制工具。
- 设计任务日志、失败复跑和数据清洗机制。
- 构建候选村庄评价指标和XHSScore评分体系。
- 整理并压缩最终SQLite交付数据库。

## 技术方向

- Python
- SQLite
- 数据采集流程
- 自动化任务控制
- Tkinter
- PyInstaller
- POI与村庄空间匹配
- 结构化数据清洗

## 数据规模

- 采集约3.25万个POI地点。
- 筛选约1.26万个候选村庄。
- 最终生成2484个正式采集任务。
- 覆盖82个城市。
- 清洗约16.69万条笔记。
- 涉及约8.89万名用户。
- 最终数据库由约890MB清洗至约172MB。

## 关键难点

- 地点与真实村庄之间存在名称和空间匹配问题。
- 不同城市的数据规模差异较大。
- 采集任务需要支持日志、失败记录和重新执行。
- 中间数据库包含大量临时字段和重复数据。
- 热点识别不能只依赖绝对笔记数量。

## 解决方式

- 使用村庄空间数据和名称规则筛选候选地点。
- 将地点发现和笔记任务解耦。
- 按城市和区县分位构建相对评价指标。
- 使用SQLite保存任务状态和阶段结果。
- 对交付数据库进行字段精简、去重和压缩。

## 项目成果

形成了覆盖地点发现、村庄识别、任务管理、数据采集和结果清洗的桌面化数据处理平台，并为乡村文旅热点识别和空间差异分析提供结构化数据基础。
